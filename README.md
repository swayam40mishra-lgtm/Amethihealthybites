# Amethi Health Bites — Landing Website

A responsive, single-page static website built with HTML, CSS and vanilla JavaScript. No framework, build step, or package installation is required.

## Files

- `index.html` — page content and section structure
- `style.css` — visual system, responsive layouts and interactions states
- `script.js` — mobile navigation and current footer year

## Run locally

1. Extract the ZIP file.
2. Open the `amethi-health-bites` folder.
3. Double-click `index.html` to open it in a browser.

For a local development server, open a terminal in the folder and run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

You can upload the three website files (`index.html`, `style.css`, `script.js`) to any static hosting service, or deploy the folder through GitHub Pages, Netlify, or Vercel. Keep all three files in the same directory.

## Before going live

- Replace illustrative food photos with actual product photos when supplied.
- Confirm product ingredients, prices, availability and allergen information.
- Confirm the exact stall address and operating hours.
- Confirm the Instagram profile URL and whether Instagram DMs are the preferred enquiry method.
- Add WhatsApp only after receiving a verified business number.
- Verify all nutrition and ingredient claims before publishing them.
- The displayed hours are explicitly marked as profile-listed and unverified.
- Product photos are illustrative, not photos of verified Amethi Health Bites products.

## Notes

- Google Fonts and images load from external URLs, so an internet connection is needed for those assets.
- The Instagram CTA points to `https://www.instagram.com/amethi_health_bites/` based on the supplied handle. Verify it before production.
- No ordering system, cart, checkout, or payment functionality is implemented because ordering requirements are not yet confirmed.
